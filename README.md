Time-Series Anomaly Detection

A machine learning project focused on detecting anomalies in time-series data from the OME dataset using deep learning models.

Key Features

- CNN Autoencoder for anomaly detection
- Simplified FEDformer with frequency-domain processing
- Time-series preprocessing and sliding-window segmentation
- Optuna-based hyperparameter optimization for CNN
- Reconstruction-error-based anomaly scoring
- Anomaly thresholding using the 95th percentile
- Model evaluation and comparison using Precision, Recall, F1-score, ROC-AUC, and confusion matrices
- Visualization of reconstruction errors and anomaly detection results

Technologies

Python, TensorFlow, Keras, NumPy, Pandas, Scikit-learn, Optuna, Matplotlib, FFT

Objective

To compare deep learning approaches for time-series anomaly detection and evaluate their ability to identify abnormal patterns in sequential data.
